▶ Tick Ingestion Flow

  1. Producer generates random stock tick events
  2. Events published to Kafka topic stock_ticks
  3. Ingestor consumes from Kafka (background thread)
  4. Each tick validated via parse_tick_event()
  5. Valid ticks routed to correct InMemoryShard
  6. Offsets committed after successful processing
  7. Bad events sent to stock_ticks_dlq (DLQ)

▶ API Request Flow

  1. Client sends HTTP request to Nginx on :8080
  2. Gateway applies rate limiting, routes to API
  3. FastAPI handles the request on :8000
  4. Storage operations route to correct Shard
  5. Response returned through the gateway to client
